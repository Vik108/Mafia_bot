# Мафия-бот для Telegram (aiogram)

Продвинутый бот для игры в мафию в группах с красивыми отчётами по партиям и системой определения героя игры.

## 🎭 Особенности

- **Красивые отчёты по партиям** с эмодзи и детальной статистикой
- **Система героя партии** - определяет лучшего игрока с уникальными шутками
- **Подсчёт убийств мафии** для определения самого опасного игрока
- **Ролевые шутки** - уникальные описания для каждой роли героя
- **Раскрытие ролей** - при исключении днём и убийстве ночью показывается роль игрока
- **Полноценная игровая механика** с ночными действиями и дневным голосованием

## Быстрый старт

1) Python 3.11+  
2) Установите зависимости:
```
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```
3) Создайте файл `.env` по примеру и задайте токен бота:
```
cp .env.example .env
```
4) Запуск (polling):
```
python bot.py
```

## Переменные окружения

- `BOT_TOKEN` — токен из BotFather.

## Команды/UX

- `/newgame` — создать игру в группе, открыть регистрацию.  
- `/join` — вступить в текущую игру (только при регистрации).  
- `/leave` — выйти до начала.  
- `/startgame` — старт, раздать роли, перейти к ночи.  
- `/status` — краткое состояние партии.  
- `/stats` — статистика чата: номер партии, победы игроков.
  - Показывает «любимую» роль игрока с эмодзи (по частоте игр):  
    мафия 😈, доктор 🩺, комиссар 🕵️, мирный 🙂
- `/forceend` — админом завершить партию принудительно.
- Автообновление состояния каждые ~15 сек: закреплённое сообщение/сообщение в чате с фазой, списком игроков и кого ждём (регистрация/ночные ходы/голоса днём).

Ночные действия приходят в личные сообщения:
- Мафия — выбор цели.  
- Доктор — выбор, кого лечить.  
- Комиссар — проверка роли игрока.  

Дневное голосование — инлайн-кнопки в группе. После голосов всех живых игроков бот подводит итог.

## 🏆 Новые функции отчёта

### Красивое оформление
- **Эффектные заголовки** с рамками из эмодзи
- **Статусы игроков** с эмодзи ролей и состояний (🟩 жив, 💀 мёртв)
- **Нумерация партий** для отслеживания прогресса

### Раскрытие ролей
- **При исключении днём** показывается роль казнённого игрока
- **При убийстве ночью** раскрывается роль жертвы
- **Драматичные сообщения** с эмодзи и стикерами для атмосферы

Примеры сообщений:
```
⚖️ Голосование завершено!
🔪 Исключён: Александр (3 голоса)
🎭 Его роль была: 😈 Мафия

☠️ Ночью был убит Мария!
🎭 Его роль была: 🩺 Доктор
```

### Система героя партии
Бот автоматически определяет лучшего игрока и генерирует уникальную шутку:

**Для мафии:**
- "Звезда ночи — Игрок! Убил 3 игрока! 🔪"
- "Король тьмы — Игрок! 3 души отправлены в небытие 🌙"
- "Мастер интриг — Игрок! Холоднокровно устранил 3 соперников! 🎭"

**Для доктора:**
- "Ангел-хранитель — Игрок! Спас столько жизней, что deserves a Nobel prize! 🩺"
- "Чудо-доктор — Игрок! Даже мафия уважает его навыки! 💉"

**Для комиссара:**
- "Орёл правосудия — Игрок! Раскрыл все мафиозные схемы! 🕵️"
- "Шериф города — Игрок! Его лупа видит всё! 🔍"

**Для мирных:**
- "Светоч правды — Игрок! Его голос был решающим! 🌟"
- "Душа города — Игрок! Мирные победили благодаря ему! 🏆"

### Разнообразные завершающие фразы
- "Реванш? 😉"
- "Ночь была длинной, а игра — горячей! 🔥"
- "Город спит спокойно... пока не начнётся новая игра! 🌃"
- "До новых встреч в тёмных переулках! 🌃"

## Ограничения/заметки

- Вся логика хранится в памяти процесса (без БД); рестарт бота обнулит партии.  
- Статистика записывается в файл `stats.json` в каталоге бота.  
- Бот пытается держать два закрепа: инструкция и текущий статус.  
- Автообновление статуса каждые ~15 сек; предупреждает и автокикает бездействующих (предупреждения за 30/15 сек, через 60 сек игрок выбывает).  
- Одна активная игра на чат.  
- Минимум 4 игрока для старта (1 Мафия, 1 Доктор, 1 Комиссар, остальные Мирные).  
- Если у бота закрыт доступ к личным сообщениям пользователя, роль/действие не дойдёт — бот предупредит в группе.
